# Default 2050 Origin playtest review

**Status:** Origin-only desk playtest completed and sponsor-approved. No Career, Incident, Fallout, runtime, or canonical setting content was authored.

## Method

Six sample characters used all six backgrounds. Each received three randomly selected, non-duplicated event families. The character chose one family, rolled unmodified 2d6, and compared A, B, a structured custom response, and The Last Run at the rolled band. This is design evidence, not an observed table playtest.

## Findings

- **Background framing:** Passed after adding one perspective-and-risk cue to each background. The same family now reads differently without granting a bonus.
- **Three-event choice:** Passed. The deals offered distinct immediate problems; Closed Route concerns route failure, while Borrowed Pass concerns credential responsibility.
- **A/B usefulness:** Passed after revising Conflicting Message / Pressure B. Other tested pairs traded asset type, visibility, responsibility, reach, or future access without a universal best answer.
- **Asset comparability:** Passed for desk play. Documents, contacts, access, and places all enter the same once-per-session lifepath invocation budget. Observed play must still test whether one category is easier to invoke in practice.
- **Obligations:** Passed after requiring a named claimant and one concrete ask. Vague debts must become another explicit hook.
- **Custom-response power:** Passed after requiring one real lasting cost and adding the three-question worksheet to this pack. GM comparison with A and B remains mandatory.
- **Callbacks and truth:** Passed. Records, people, routes, reviews, duties, and access logs create concrete callbacks without deciding which branch, message, or record is cosmically true.
- **The Last Run:** Passed after preserving the selected connection when safe and permitting a neutral replacement without explanation. Its outcome budgets match the primary families.
- **Full flow:** Clear and enjoyable in this desk pass. Choice before the roll created authorship; the band changed the kind of pressure; the final response changed persistent history. The next evidence should be an observed table playtest, not more phase authoring.

## Sponsor-approved revisions

1. Add one framing cue to each background.
2. Let Conflicting Message / Pressure B preserve both tasks for a short time.
3. Require every obligation to name who can call it in and one concrete ask.
4. Require every custom response to include one real lasting cost.
5. Tie The Last Run to the chosen connection when safe, with a neutral substitute when needed.
6. Put the three-question custom-response worksheet directly in the Origin pack.

## Stop gate

The sponsor approved the revised Origin pack after this review. Do not author Career, Incident, or Fallout and do not implement runtime code without separate authorization.
